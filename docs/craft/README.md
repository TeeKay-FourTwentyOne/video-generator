# Craft guides

On-demand reading for a shot or a technical problem. The maintained workflow is
`docs/production.md`; load these only when the work needs them.

| File | Use when |
| --- | --- |
| `core-workflow.md` | Directorial planning; catalog of historical MCP primitives |
| `clip-acceptance-gate.md` | Accepting a generated take (frame-qa, clip-qa, clone-check ladder) |
| `veo-techniques.md` | Veo prompt and limitation basics |
| `ffmpeg-knowledge.md` | Frame-accurate trims, encodes, stream copy pitfalls |
| `editing-system.md`, `dialogue-system.md`, `narrative-model.md` | Legacy edit, dialogue and narrative structures |
| `agents.md` | Historical SDK agents (not the production path) |
| `field-notes/` | Dated, attributed lessons about model behavior, anchors, QA, editing, sound and direction. Any agent appends; see its README |

Harness-specific notes (what the shell, sandbox and tools do under Claude Code
versus Codex) live in `docs/harness/`, not here.
