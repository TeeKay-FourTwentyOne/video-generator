# SECOND SPEAKER: dubbing an invented language

Source: claude-code · SECOND SPEAKER · 2026-11-23

### Check invented words against real languages before the director sees them
The first six-word lexicon went to the director and was approved. A web search
afterwards found four of the six were real: the self-name of a people, the name
of a people and their language, an ordinary phrase in a third language and a
near-homophone of a common family word in a fourth. One replacement collided as
well. Short open-syllable words are exactly what real languages are made of.
**Apply:** search every invented word, and each replacement, before presenting
the list. Say that the check is a search and not a proof, and keep a rule for
replacing a word on a credible report.

### A guide performance plus speech-to-speech holds mouth timing in a language the model has never heard
Each on-camera line was generated by Veo with the quoted syllables and a
lowercase phonetic hint in parentheses, then converted to the cast voice with
ElevenLabs speech-to-speech. Thirteen takes, all first attempts, all in the
cut; a local transcription of the mix returned the lines in script order. Text
to speech was used only for the device, which has no mouth.
**Apply:** for invented or uncommon speech, let the motion model perform the
line and convert the voice afterwards. Keep lines to one short phrase per take.
Voice the off-camera character first and treat its reading as the pronunciation
reference.

### Veo restyles hair late in a take
The hairstyle set by the anchor drifted to a bun or a ponytail in the last
seconds of three takes.
**Apply:** state the hairstyle in the motion prompt, and plan the cut to leave
before the drift; here that meant using the first three to four and a half
seconds of six-second takes.

### The upscaler's default quality did not match the masters
`tools/upscale.py` encoded at CRF 18 by default while recent masters were made
with `--crf 16`. A run started with the default had to be restarted.
**Apply:** the default is now 16. Record the exact command in the delivery
record either way.
