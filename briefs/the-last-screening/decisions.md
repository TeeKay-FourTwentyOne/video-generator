# The Last Screening — historical recipe compatibility

[Project overview](README.md).

The archived `scratch/record-upscale-4k.py` reads the old flat brief paths as text. Those paths now
forward human readers and must not be copied as publication wording or edited
as though they were full briefs.

For a future rebuild, first copy the archive into a new active workspace. Update
the restored script to use `briefs/the-last-screening/brief.md` for current documentation, or the pre-migration brief in the ignored migration receipt
for the historical wording. Do not run the old source-writing script against
the archive or the forwarding pages. No archived recipe, media, manifest or
historical description was changed by this documentation migration.
